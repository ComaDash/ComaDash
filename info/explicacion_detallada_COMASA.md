# Explicación detallada del archivo “Agua, Vapor y Condensado Planta COMASA”
Este informe interpreta cada hoja y cada fila con datos. El Excel funciona como un mapa de puntos de medición del ciclo agua–vapor–condensado de la planta: indica desde dónde viene una corriente, hacia dónde va, qué tipo de fluido es, qué variable se mide, con qué unidad, qué valor aparece, qué instrumento/TAG entrega el dato y a qué etapa del proceso se asocia.
## Cómo leer las columnas
| Columna | Significado | Qué permite preguntar | Datos que responden |
|---|---|---|---|
| Desde | Equipo, estanque o punto de origen de la corriente. | ¿Dónde nace este tramo del proceso? | Nombre del origen. |
| Hasta | Equipo, estanque o punto de destino. | ¿Hacia dónde va la corriente? | Nombre del destino. |
| Variable | Tipo de fluido o corriente: agua industrial, agua desmineralizada, agua de alimentación, vapor, condensado, refrigeración. | ¿Qué fluido está circulando? | Categoría de fluido. |
| Variable de medición | Magnitud medida: flujo, presión, nivel, temperatura, carga, revolución. | ¿Qué condición física/control se está midiendo? | Tipo de medición. |
| U. de medida | Unidad física: m3/h, ton/h, bar, °C, %, A, rpm, mmH2C. | ¿En qué escala se expresa? | Unidad. |
| Medición | Valor registrado para ese punto. | ¿Cuánto mide actualmente? | Valor numérico o indicador de falta de dato. |
| TAG | Código del instrumento o señal. | ¿De qué sensor/señal sale el dato? | TAG de instrumentación. |
| Etapa | Agrupador lógico del proceso. | ¿A qué etapa del recorrido pertenece? | Número/nombre de etapa. |
| Columna I | Notas ocasionales; casi siempre vacía. | ¿Hay comentario adicional? | Texto de nota. |

## Lectura global del proceso
El recorrido general es: pozos/captación → estanque de agua industrial → osmosis/tratamiento → agua permeada/desmineralizada → desgasificador/desaireador → agua de alimentación → economizadores/ECO → domo → sobrecalentadores → turbina → condensador → retorno como condensado. En paralelo hay circuitos de refrigeración hacia torre, generador, unidad hidráulica y condensador.

## Regla para convertir una fila en pregunta
Cada fila genera una pregunta de control con esta forma: **¿Cuál es [Variable de medición] de [Variable] en el tramo [Desde] → [Hasta] para [Hoja/Unidad], y qué instrumento lo mide?** La respuesta se arma con **Medición + Unidad + TAG + Etapa**. Cuando la medición aparece como `----`, `-----`, celda vacía o `0`, no basta para concluir: se debe validar si es dato faltante, equipo detenido, señal sin configurar o condición operacional real.
